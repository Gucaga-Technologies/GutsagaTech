PHOTOS — WHERE TO DROP THEM (I wire everything else automatically)
===================================================================
All slots below are already built into the pages. Save a photo with the
exact filename into the exact folder — refresh the page, it appears.
Recommended ~1200x675 JPG.

1) EVENT PHOTOS  ->  folder: assets\news\
   istanbul.jpg   (Retail Days 2026 booth photo)
   kyiv.jpg       (Kyiv expo booth photo or booth render)

2) INDUSTRY PHOTOS  ->  folder: assets\img-ind\
   One per industry, e.g. pharmacy.jpg, fmcg.jpg, automotive.jpg ...
   Full list + suggested stock searches: assets\img-ind\README.txt
   Or run automatically:  python scripts\download_industry_photos.py
   (free API key from pexels.com/api — script asks for it)

Everything else on the site (logos, screenshots, blog photos, banners,
the hero animation) is already in place and working.
