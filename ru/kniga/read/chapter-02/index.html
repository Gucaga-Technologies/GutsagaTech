Как сделать денежный поток больше?

ГЛАВА 2

Четыре базовых механизма — и один из них меняет саму границу рынка

К этому моменту вы уже знаете: готового ответа со сцены не будет. Каждый следующий шаг снова возвращается в зал — и сначала проходит через вас.

Спикер: Хорошо. Тогда как сделать денежный поток рынка больше? Какие есть варианты?

Из зала: Поднять цену.

МЕХАНИЗМ 1

Цена: больше денег за тот же объём

Если при том же объёме лечения единица товара стоит дороже, через рынок проходит больше денег. Самый прямой механизм.

Спикер: Можно поднимать цену бесконечно?

Из зала: Нет.

Из зала: Есть регулирование.

Из зала: Есть конкуренты.

Из зала: Пациент просто не сможет платить.

В ответах уже меньше страха ошибиться и больше азарта. Вы тоже невольно проверяете каждую реплику на собственной компании.

Цена способна увеличить поток, но у неё есть предел: покупательная способность, конкуренция и регулирование — часто всё одновременно.

Спикер: Как получить в систему больше денег, не ограничиваясь только тем, что пациент заплатит в аптеке сегодня?

Из зала: Страхование.

МЕХАНИЗМ 2

За лечение платит не только пациент

Спикер: В страховой модели пациент может не оплачивать лекарство непосредственно в момент покупки. Часть медицинской потребности финансируется через другого плательщика.

Из зала: И работодатель может платить.

Страховщик, работодатель или государство могут стать другим плательщиком. Это не создаёт новые экономические ресурсы само по себе: меняется механизм финансирования, расходы распределяются во времени, а барьер оплаты в момент лечения снижается. При определённых правилах это может увеличивать эффективно профинансированный спрос.

МЕХАНИЗМ 3

Дополнительные услуги

Спикер: Что ещё может создать дополнительный доход вокруг существующей инфраструктуры?

Из зала: Диагностика.

Из зала: Консультации.

Из зала: Вакцинация.

Из зала: Другие медицинские услуги.

Теперь первоначальная рамка расширяется: речь уже не только о том, как продать больше лекарств, а о том, какими путями в систему может войти больше денег.

Где законодательство и модель рынка это позволяют, услуги становятся ещё одним источником денежного потока.

Спикер: А есть способ принципиально другого типа?

Спикер: Не брать больше денег за существующую потребность. Не добавлять нового плательщика. Не добавлять услугу вокруг лечения. Что тогда?

Из зала: Продавать что-то ещё.

Спикер: Например?

Из зала: Косметику.

Из зала: Детские товары.

Из зала: Средства ухода.

Из зала: Товары для здоровья и ухода за собой.

И здесь возникает другой сдвиг. Для покупки многих таких товаров человеку необязательно нуждаться в лечении. Аптека начинает работать уже не только с деньгами, направленными непосредственно на медицинскую потребность.

Вы смотрите на четыре базовых механизма и замечаете: вопрос, который несколько минут назад казался слишком большим для одного слайда, уже превратился в карту.

  1. ЦЕНА

    Больше денег за существующую потребность.

  2. ДРУГОЙ ПЛАТЕЛЬЩИК

    Дополнительный источник финансирования лечения.

  3. УСЛУГИ

    Доход вокруг лечения и инфраструктуры.

  4. НЕ ТОЛЬКО ЛЕКАРСТВА

    Доступ к расходам, не связанным только с лечением.

Первые три механизма меняют экономику внутри медицинской потребности: цену, финансирование или услуги. При определённых правилах они могут увеличивать профинансированный спрос. Четвёртый выводит аптеку за пределы лекарств. Не исчерпывающая классификация: объём лечения меняется также через диагностику, доступ и приверженность терапии.

Хорошо. Деньги есть. А кто их получит?
